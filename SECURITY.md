# Security
This is a prototype. It does not authorize or execute real tasks.

The server binds to 127.0.0.1 and serves an allowlist of static assets. Microphone capture is opt-in; browser speech services may process audio remotely. Queue data exists in memory and is lost on reload.

Use synthetic examples. Never submit credentials or private conversations in issues or pull requests.

## Reporting
After this repository is published and private vulnerability reporting is enabled, use its GitHub **Security -> Report a vulnerability** flow. Until that channel is configured, do not publish exploit details or sensitive material in an issue.

No security response SLA or production support is promised during this prototype stage.
